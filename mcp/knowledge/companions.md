# Companion MCP servers

**Purpose:** Other apps have their own MCP — catalog only from v1d.

| MCP id | App |
|--------|-----|
| `inkscape_mcp` | Inkscape |
| `open_chat_cut_mcp` | OpenChatCut |
| `kdenlive_mcp` | Kdenlive |
| `usd_composer_mcp` | USD Composer |

**Allowed:** Name them in agent replies; use `v1d_catalog`.

**Forbidden:** Reimplement their tools inside `v1d_mcp_server.py`.

**Detail:** [mcp/catalog.json](../catalog.json).
